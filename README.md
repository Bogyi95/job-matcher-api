# 🚀 Job Matcher API

A full-stack application that analyzes a CV and matches it with real job offers based on skills.

---

## ✨ Features

-  Extracts skills from a CV  
-  Scrapes real job offers  
-  Calculates a match score for each job  
-  Highlights missing skills  
-  Provides improvement suggestions  

---

## 🛠️ Tech Stack

### Backend
- Python  
- FastAPI  
- Playwright  

### Frontend
- React  
- Axios  

---

## ⚙️ How It Works

1. Paste your CV text  
2. Skills are extracted from the CV  
3. Job offers are fetched from online sources  
4. Skills are extracted from job descriptions  
5. A match score is calculated for each job  
6. Results are displayed in the UI
