job-matcher-api is a full-stack application that analyzes a CV and matches it with real job offers based on skills.

Features:
-extract skills from CV
-scrapes job offers
-calculates match score for each job
-highlights missing skills
-provides improvement suggestions

Tech Stack:
  Backend:
  -Python
  -FastAPI
  -Playwright

  Frontend:
  -React
  -Axios

How it works:
-paste CV text
-skills are extracted
-jobs are fetched
-skills from jobs are extracted
-match score is calculated
-results are displayed
